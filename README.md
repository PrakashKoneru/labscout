# Labscout

**Deal Flow — NYC's first VC hackathon** · Betaworks · October 24, 2026
**Track 1: Sourcing** — find the founder before the round.

Labscout surfaces technical founders before they raise, from public research and builder signals — grants (NSF, SBIR), arXiv papers, patents and GitHub — and writes a one-page "why this founder" brief for every lead, with every claim linked to its source.
