2. The four sponsors, live

NicrronNinoo

LLM gateway. Turns the VC's thesis into academic search keywords, then writes the 3-line "why this student deserves a coffee" brief per candidate.

Endpoint: POST https://api.nicrron.ai/v1/chat/completions · model anthropic/claude-haiku-5-5
When: step 1 (keywords) and step 4 (briefs)
lib/llm.ts

PRISM by Block Convey

Agent observability. Every model call and every search is traced, so we can audit what the AI said about each student and how long it took.

Endpoint: POST https://prism.blockconvey.com/api/traces
When: after every LLM call + once per search (fire-and-forget)
lib/prism.ts

akta.pro by Wokelo AI

News Signals. Pulls recent market news on the thesis ("is the market moving?") and press mentions for the top 5 students, filtered against namesakes.

Endpoint: GET https://api.akta.pro/api/v1/news/ (query= and entity_person_list=)
When: step 2, in parallel with OpenAlex; step 4 for the top 5
lib/akta.ts

Roundtable

Shared agent workspace. Each shortlist is saved as a versioned markdown file other agents and partners can read and build on.

Endpoint: POST https://roundtable.bot/api/tools/write_file
When: last step, once the ranked list is final
lib/roundtable.ts
