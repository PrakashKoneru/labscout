1. Use the product

  1. Open the app. Type the fund's thesis in plain English, for example "students working on protein design with diffusion models", or click one of the example chips.
  2. Click Find students. It takes 10–20 seconds. The progress line shows each stage: reading the thesis, searching OpenAlex and akta.pro, checking ORCID, writing briefs, saving to Roundtable.
  3. Read the results, top to bottom:
    • Market pull panel: recent news on the thesis from akta.pro, with AI summaries. This answers "is the market moving?"
    • Ranked cards, one per student: name, school, and a green Current student badge when ORCID confirms an education entry with no end date. "Unverified" means there was no ORCID data. It doesn't mean they're not a student.
    • A 3-line brief: what they published, why it fits the thesis, and the one question to ask them.
    • Evidence: up to 3 matching papers (author position, year, venue, link). Footer links go to OpenAlex and ORCID. Hover over score ⓘ to see exactly how the rank was computed.
    • Press mentions (akta.pro) appear only when an article names the student and their university or a thesis keyword. That filter keeps out people with the same name.
  4. Copy brief on any card puts a forwardable text with sources on the clipboard. Paste it into an email to a partner.
  5. The bottom line shows where the shortlist was saved in Roundtable, plus a ● Nicrron ● PRISM ● akta.pro ● Roundtable status row. A filled dot means that integration ran.

How the ranking works

  • +10 for each matching paper as first author, +3 as a middle author, +1 as last author. Plus up to +5 for citations and +2 if published in 2025 or later.
  • +15 for a student confirmed by ORCID, −15 when ORCID shows their education has ended.
  • Momentum: up to +10, based on the share of the author's papers from the last two years. Recent growth counts more than a long career total.
  • Penalties for established researchers (more than 30 papers, or publishing since before 2018). This keeps faculty below students.

Coverage: Columbia, NYU, Cornell and Cornell Tech; papers from 2024–26. The list of schools is in lib/institutions.ts.

Queries that demo well

2. How we use the sponsors

All four required sponsors run on every search. The status row under the results shows which ones ran.

SponsorWhat it does in LabscoutCode
NicrronNinoo All LLM work goes through the Nicrron gateway (model anthropic/claude-haiku-5-5). It turns the thesis into search keywords and writes the 3-line brief for each top-10 student. lib/llm.ts
PRISM by Block Convey Every model call is traced to PRISM, plus one summary trace per search. All traces from one search share a session_id (search:<query>), so the whole run appears as one conversation. Agents: query-parser, brief-writer, search-orchestrator. lib/prism.ts
akta.pro by Wokelo AI News Signals API. (1) The Market pull panel: topic news on the thesis keywords, with AI summaries, sentiment and the companies mentioned. (2) Press mentions: a person search on each top-5 student, filtered by university or thesis keyword. This is our entry for Best Use of External Data. lib/akta.ts
Roundtable Each search writes a versioned markdown shortlist (brief, evidence, score reasons, links) to labscout/<query-slug>.md through Roundtable's write_file tool. Any agent in the workspace can read it: the shortlist becomes shared memory for other agents (a diligence bot, a CRM bot), not a dead-end UI. lib/roundtable.ts

Data sources (free, no keys needed): OpenAlex for papers and authors, ORCID public API for education history. We don't scrape LinkedIn or Google Scholar.

Each integration fails safely. If a key is missing or a service is slow, that panel is skipped and the search still returns results.

3. REST API

POST /api/search takes JSON {"q": "<thesis>"} and returns the full result. No auth. Allow up to 60 seconds; usually it takes 10–20. Repeating a query on the same server instance comes back from cache instantly.

curl -s -X POST https://labscout-jakdemir.vercel.app/api/search \
  -H 'content-type: application/json' \
  -d '{"q":"AI for drug discovery"}'

4. MCP endpoint

Labscout is also an MCP server, so any agent can source students as a tool call.

URLhttps://labscout-jakdemir.vercel.app/api/mcp
TransportStreamable HTTP. Stateless, JSON responses, no auth.
Toolsearch_students(query: string, limit?: 1–10) returns a markdown shortlist plus the full JSON in structuredContent.

Claude Code

claude mcp add --transport http labscout https://labscout-jakdemir.vercel.app/api/mcp

Cursor / Claude Desktop / any client with remote MCP

{
  "mcpServers": {
    "labscout": { "url": "https://labscout-jakdemir.vercel.app/api/mcp" }
  }
}

For a client that only supports stdio servers, wrap it: "command": "npx", "args": ["-y", "mcp-remote", "https://labscout-jakdemir.vercel.app/api/mcp"].

Hermes Agent (~/.hermes/config.yaml)

mcp_servers:
  labscout:
    url: https://labscout-jakdemir.vercel.app/api/mcp

Test it with curl

curl -s https://labscout-jakdemir.vercel.app/api/mcp -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

curl -s https://labscout-jakdemir.vercel.app/api/mcp -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"search_students","arguments":{"query":"robotics manipulation","limit":3}}}'

Then ask your agent: "Use labscout to find students working on battery materials and draft intro emails for the top 3."

6. Run & change the code

No dependencies and no build step: Node 22.6+ runs the TypeScript directly.

git clone https://github.com/jakdemir/labscout && cd labscout
# create .env.local with your own keys (names only shown here):
#   NICRRON_API_KEY=…          required (LLM)
#   OPENALEX_MAILTO=you@…      recommended
#   AKTA_API_KEY=…             optional
#   PRISMTRACE_API_KEY=…  PRISMTRACE_PROJECT_ID=…   optional
#   ROUNDTABLE_KEY=…           optional
node scripts/dev.ts             # http://localhost:3000  (also /docs, /api/search, /api/mcp)
node --test tests/*.test.ts     # unit tests

7. Demo script (about 3 minutes)

  1. Problem (20 s). "Every fund chases the same founders on LinkedIn at the same time. The best technical founders show up in papers and grants 18 months before they incorporate."
  2. Live search (60 s). Type a judge's thesis. Show the Market pull panel (akta.pro), then the #1 card: badge, brief, evidence links, and the score ⓘ breakdown.
  3. Forwardable (15 s). Copy brief, paste into an email.
  4. Agent-native (30 s). Open Roundtable and show the saved shortlist file. Run the same query from Claude through the MCP endpoint. Open PRISM and show the traces for that search.
  5. Business (45 s). Buyer: platform teams and associates at pre-seed funds. Price: about $5–10k per fund per year. First 10 customers: the funds in this room. Why now: open research data plus LLM briefs make this cheap for the first time.

If the Wi-Fi fails, use /?mock=1.
